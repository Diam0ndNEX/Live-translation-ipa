Branch `claude/screenlingo-v2.0.0`. Everything here comes from **reading** the code at build 84.

every U-item must be gone in 2.0.0.

## U1: "some tabs don't work": cause NOT found by reading

I read RootView and every `selectTab` call site. The numbers match the current tab tags, so no call opens a wrong tab today:

| Call site | Number | Tab it opens |
|---|---|---|
| HomeView.swift:113 | 1 | Languages |
| HomeView.swift:238 | 1 or 0 | Languages / Live |
| HomeView.swift:307 | 3 | Activity |
| SettingsCategories.swift:171 | 3 | Activity |
| Diagnostics.swift:2416 / 2417 | 1 / 0 | Languages / Live |

Nothing in the tab structure is broken by reading. Candidates that I could not confirm or rule out without running:
1. `selectTab` uses bare integers (fragile; any reorder breaks silently).
2. Every tab observes the whole 246 KB engine (U3); heavy redraws could look like a frozen tab.
3. Diagnostics (Activity tab) renders nothing until `onAppear` sets `visible` (Diagnostics.swift:2134, 2159, 2233). A missed `onAppear` shows an empty tab.
4. Diagnostics has a NavigationStack inside a tab and opens another NavigationStack inside a sheet (Diagnostics.swift:2157, 2231).
5. Settings: `ResetSection` attaches a `confirmationDialog` straight to a `Section` inside a `List`; presentation there is unreliable, so "Reset this page" may do nothing.

**Report to me:** which tab, what you tap, and what happens (blank / no response / wrong screen / crash). Until then this is unverified. 2.0.0 removes all five candidates by design (router, narrow view models, no `visible` gate, one NavigationStack per tab, dialogs on the owning view).
