## How
- TranslationSystem, TestRunViews: whole top-level types moved, text unchanged, no access change.
- SampleHandler, ModeTranslationService, TranslationMemoryStore: members moved into extensions with the rules in `docs/structure-migration-plan.md` (2.3.7 section). Access-only changes: SampleHandler 34, ModeTranslationService 16, memory store 10. The `Admission` type lost `private` because an internal method returns it.
- `processSampleBuffer`, `send`, `encode`, `translate`, `createSchema`, `upgradeSchemaV2`, `lookupBody` and every member tests match by text stay in the main files.

## CI and scripts
- `build.yml` named `Shared/TranslationSystem.swift` in 5 swiftc lines. Those lines now use `$(bash scripts/swift_sources.sh TranslationSystem)`. The owner applies the file by hand; until then the "checks" job fails to compile those steps.
- `test_diagnostics.sh` and `test_test_runs.sh` use the same helper.
- Five tests read these files through `read_source`.
