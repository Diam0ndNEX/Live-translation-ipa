# ScreenLingo v1.5.0 — Diagnostics dashboard and evidence ZIP v3

## Purpose

Make v1.5.0's more complex offline recognition/translation system diagnosable with normal/tail latency, subtitle continuity, speculative model work, memory and experiment settings. Version 1.4.6 → 1.4.7 regressions demonstrated that **P95 alone is not an acceptable performance metric**: median/mean, confirmed-but-unenqueued work, and visible subtitle stability must be reviewed together.

No server upload, video frame recording, audio capture, or raw subtitle-text capture is added. Diagnostics run locally. A ZIP export is always user initiated.

## Updated in-app diagnostics

The Simple and Detailed Overview pages now start with a **Test evidence** card showing median/mean/P95 for OCR-sighting→PiP enqueue, candidate confirmation and successful enqueues, confirmed-but-superseded candidates, discarded speculative jobs, RAM-retained units and pre-translation reuse.

- The card prominently offers **Export complete diagnostic ZIP**, and explains the measurement boundary.
- Settings → **Diagnostics & tests** links to the live dashboard and includes ZIP export and feedback.
- Existing detailed graphs, timeline, privacy-safe candidate correlation, language, device, memory, saved-session comparison, simulation and other report/CSV export remain available.
- The text report includes new model/OCR/PiP feature flags, confirmed candidate continuity and retained speculation counters.
- Evidence-based findings now distinguish suspected typical latency, suspected slow-tail latency, confirmed work superseded before PiP enqueue, and observed enqueue failures.

## ZIP format v3

Eight flat, fixed-name entries:

| File | Contents |
|---|---|
| `manifest.json` | schema version, session UUID, range, file inventory, privacy and measurement boundary |
| `summary.md` | first-open human-friendly summary, median/mean/P90/P95, continuity, cache, memory, settings, findings and limitations |
| `session.json` | backward-compatible canonical structured metrics/events/session export (new `exportFormatVersion=3`) |
| `intervals.csv` | 15-second time buckets, thermal and power levels, OCR/translation/enqueue timings and counters |
| `metrics.csv` | sanitized metric name, sample count, mean, median, P90, P95, P99 and maximum |
| `events.csv` | anonymized, chronological candidate/frame/unit UUID correlation with stage/outcome/reason/duration |
| `findings.json` | fixed-code observed/suspected findings, counts and explanations |
| `README.txt` | data dictionary, privacy and measurement caveats |

ZIP file names include the session UTC start time and a short opaque identifier. The ZIP uses the already tested standards-compatible stored-entry encoder (no new compression dependency) and existing atomic protected write.

## Settings consistency

The structured session now snapshots important v1.5.0 flags:
`lowLatencyTranslation`, `incrementalBatchRecovery`, `directPiPBuffer`,
`subtitleAwareChangeDetection`, `preserveRelatedMovieGroups`,
`deduplicateCopies`, `contextualLanguage`, `languageRecovery`,
`continuousRotation`, `smartCool`, `persistDiagnosticSessions`,
`diagSamples`, `heartbeatInterval` and `keepAwake`.
All values pass strict key and scalar-value allowlists. Unknown counters, metrics,
event codes or potentially sensitive free-form settings stay out of the export.
When the same video is replayed with two different strategies, the settings
differ, so the existing strict comparator rejects a misleading controlled A/B claim.

## Counter definitions and limitations

- **Confirmed candidate packets** and **successful candidate enqueues** count different events and are not necessarily one-to-one.
- **Unpresented confirmed** means a confirmed candidate was superseded before enqueue, not a missed human-visible subtitle.
- **PiP enqueue** is an OS buffer submission, NOT proof that the frame was displayed.
- No diagnostics can count subtitles OCR never recognized without independent video ground truth.
- **Speculative attempts/discards** count pipeline jobs. **Retained results/cache hits** count translation units/sentences. Do not sum them.
- **Median** is typical measured delay; P95 is a slow-tail indicator. Both are bounded and cannot independently establish a full-video speedup.
- 15-second intervals contain session deltas; aggregate totals survive recent structured-event ring eviction.
- Thermal and settings behavior can vary while testing. Actual battery/performance changes require a controlled device test.

## Verification

`scripts/test_diagnostics.sh` compiles the portable archive and its tests. Tests cover old JSON decoding, versioned ZIP file inventory, system `unzip -t` and `unzip -p` interoperability on macOS, manifest flags, privacy redaction, known metrics/unknown-metric sanitization, settings flags and evidence detector sample thresholds.

The workflow also runs the app/extension iOS Release build and IPA artifact check. Real-device acceptance still requires export/share-sheet testing, 5-minute paired-video diagnostics with the same language and settings, normal latency, missing/extra captions, battery/temperature, and confirmation that no extra diagnostic overhead harms capture.
