# ScreenLingo v1.7.1 (55)

Base: ce87aa941386927cdc286cae160810094a6cf88b (v1.7.0 build 54).
Scope: all proposed v1.7.1 testing/diagnostic fixes, exact scheduling/reuse changes.
Never modify main. No claim of measured device speedup or quality parity.

## Three testing policies

| Mode | Saved translation lookup | RAM | Speculation | New persistent translations | New history |
|---|---|---|---|---|---|
| Normal | User settings | Normal bank | User settings | User settings | User settings |
| Fresh requests only | Bypassed | Bypassed | Disabled | Disabled | Previous fresh-test behavior |
| Temporary-memory test | Disabled | Separate process bank | User settings | Disabled | Disabled |

Temporary-memory test is a default-off toggle under Diagnostics & tests. Switching
to YouTube, foreground/background transitions, diagnostic resets and toggle off/on do
not erase its bank. A new process constructs empty banks; there is no Codable/disk
representation. No additional Start/End/reset controls. The existing bounded RAM
capacity and memory-pressure eviction rules still apply. Normal memory management
clears normal RAM, not the temporary bank. Retry bypasses reuse without erasing the
temporary bank. Normal RAM/provenance/LRU are separate and restored when returning
from the test. The setting itself is saved; the entries are not.

Only one test toggle is selected interactively. Conflicting bulk-imported values
resolve to strict fresh-only mode. Mode changes invalidate old work and start a new
diagnostic cohort. Existing pending normal-mode durable writes may finish; temporary
results cannot enter that queue. Database health/diagnostic metadata remain available;
"no saved-memory access" means no translation retrieval, not disabling diagnostics.

The fresh-test D83D8930 run recorded 106 confirmed batches, no speculation/reuse,
625ms median / 714ms mean / 1200ms P95 and 8 superseded confirmed candidates.
It measures a stricter path than new-video playback with speculation available.
The regular 75A36C70 run had 3 misses, 287/323/498ms and 1 superseded confirmed
candidate. Temporary mode fills the missing realistic unfamiliar-content experiment.

## Scheduling and quality invariants

- Real processing and overlap checks share clean-up, slang, dialogue, protected-token
  and sentence preparation. Existing segmentation boundaries remain unchanged.
- When selected-source speculative model work contains an exact unit needed by a
  newer candidate in the same context, do not cancel it merely because the whole
  block changed. Completed results still enter only exact-key RAM. Old captions
  remain invalid for presentation; all current caption units must assemble normally.
- In-flight overlap is disabled for Automatic source, fresh-only/bypass, cancelled
  tasks and changed work context. No guessed source, fuzzy keys, new concurrent live
  model session, reduced OCR detail or model-strategy substitution.
- An already assembled, exact selected-source caption can bypass an occupied model
  lane. Its key includes length-framed raw block boundaries, source/target and the
  existing rule/model digest. It cannot display partial results or skip confirmation,
  frozen/paused guards, recency checks or configured presentation holds. Bounded to
  64 captions per RAM bank. It adds no persistent storage.
- Confirmed-caption grace protection remains in force. Queue counters identify waits
  behind confirmed work, speculative work and ordinary scheduling. This release does
  not cancel the reusable TranslationSession, which would invalidate future requests.

## Diagnostics and comparison fixes

- Export suppressOwnInterface, both fixed visibility events, and completed confirmed
  recovery counts through privacy allowlists. Private strings remain rejected.
- lookupMisses now means actual recorded database misses in both session and interval
  counters. uncachedUnits counts model-needed units, bypassedLookups counts deliberate
  bypass, temporaryMemoryMisses counts misses in the process bank.
- Saved-origin results include prefetch into RAM; label them accordingly, and show
  direct persistent outcomes separately. Do not add overlapping provenance counters.
- Export temporaryMemoryHits, exactCaptionHits, exactUnitsCoalesced, sharedInFlightUnits,
  speculativeUnitsRetained/Reused/EvictedUnused and per-owner queue timing. These are
  different event units, not a unique-subtitle coverage or energy-efficiency metric.
- Export effective translationTestMode and startingRAMEntries. Snapshot effective
  mode before ending a cohort so a toggle does not relabel its predecessor. Ignore
  model completion timing from an earlier diagnostic epoch.
- Live RAM count at export comes from the active bank; temporary mode needs no save
  operation to refresh that count. Pipeline simulation applies the same three policies.
- Comparison tool rejects different effective test modes or known different starting
  RAM counts. Existing fixed 40-cell/90% matrix is unchanged. Missing lookup timing in
  fresh-only mode cannot be invented to pass the normal-operation acceptance gate.

## Validation

CI: existing pipeline tests plus process-bank lifetime/isolation, exact caption identity
and bounds, shared unit/context policy, real archive privacy roundtrip of new fields,
SQLite fault/migration/recovery, local UDP, Python settings/comparison regressions,
storage benchmark and Release app/extension compilation/IPA metadata packaging.

Authoring environment has no Swift/Xcode. Native tests/build are run on macOS CI;
Python checks do not establish Swift compilation or device behavior.

Required device acceptance:
1. Enable temporary toggle and replay the same video with normal Balanced. Persistent
   hit/write counts must stay zero for temporary outputs; temporary reuse and actual
   speculative submissions should appear when content permits.
2. Switch to YouTube and return; toggle temporary off/on and reset diagnostics. Entries
   remain. Terminate/relaunch the process: temporary entries begin at zero while saved
   translations/history remain. Do not confuse backgrounding with process termination.
3. Verify language/rules/model/private/fresh changes during in-flight work cannot leak
   results between banks, contexts, saved memory or history.
4. Growing and rapid subtitles: inspect wording/order/coverage/flicker against source.
   Track shared units, queue-owner durations and superseded confirmed candidates. No
   partial caption should appear. Keep low-latency off for the normal-model objective.
5. Repeat normal, temporary and fresh-only cohorts separately with matching starting
   conditions; do not claim a percentage speedup from mixed modes or warmed replays.

Remaining limits: actual model execution is unchanged; task cancellation is cooperative;
full-request quality, timing, heat, power and continuity need device measurements.
Automatic-language overlap/whole-caption acceleration is deliberately not guessed.
