# ScreenLingo 1.5.0 — optional optimization experiments

## Scope and safety

This supplements `docs/v1.5.0-acceptance.md`, based on the 1.4.7 regression comparison. All new experiments are OFF by default. The app preserves accurate Vision OCR, language correction, required stability reads, full caption presentation, SQLite durability, and the existing translation path. No internet service or external translation provider was added.

## Implemented and research

| Setting / improvement | Code | Why | Cautions |
| --- | --- | --- | --- |
| **Low-latency translation models** (off) | Performance & power, `TranslatorEngine` | Select Apple's `TranslationSession.Strategy.lowLatency` when available (iOS 26.4+). Match `LanguageAvailability` to the chosen strategy, rebuild live/warm sessions, include the strategy in the memory-rule digest. The old default model route remains available. | Traditional models may be less fluent; unsupported combinations must be explained; never label an alternate model's result as a cache hit for the other strategy. |
| **Subtitle-area change sampling** (off) | Reading & OCR, `SampleHandler`, `Config` | Optionally sample 48 columns over the selected OCR region, use BGRA luminance instead of blue-only bytes, fall back to full-frame sampling on rotated captures. Existing max unchanged delay triggers periodic OCR. | Small pixels may still be missed; measure missed subtitles against default and preserve periodic read. |
| **Related Movie lyrics groups** (off) | Reading & OCR, Movie selection | Keep additional similarly aligned, nearby, substantial text groups when the user explicitly enables the experiment. | Can include unrelated interface text; not a universal OCR text classifier. |
| **Incremental speculative batch reuse** (off) | Performance & power, `TranslatorEngine` | For multi-unit on-device speculative calls, `translate(batch:)` yields individually completed results. Retain only nonempty uniquely mapped exact-key units in bounded RAM in the same context. | Never publish partial captions or persist unconfirmed work. If batch fails, confirmed handling still retries. |
| **Direct PiP buffer rendering** (off) | Performance & power, `PiPRenderer` | Reuse the current pixel buffer pool and draw text into a BGRA bitmap context, avoiding the intermediary UIImage path when enabled. | Rendering parity (orientation, fonts, colors) is NOT proven. Switch off immediately if differs. Normal screenshot export still uses UIImage. |
| **OS signposts** (always, numeric only) | OCR, TranslationBatch and PiPFrame | Measure instrumentable phases with `OSSignposter` without OCR text or translated content in marker payloads. | Instruments trace requires developer tooling; does not replace user-facing diagnostics. |
| **PiP queue backpressure** (always) | `PiPRenderer` | Avoid redundant *heartbeat* sample buffers when `sampleBufferRenderer.readyForMoreMediaData` is false. Fresh subtitle enqueues still execute. | Watch for spinners/stalls on long idle scenes. |

## Test and acceptance matrix — not yet completed

1. **Compile** the app and extension for iOS Release with latest stable Xcode; verify metadata and IPA artifact. Swift/Xcode not available through the GitHub connector; GitHub Actions is the authoritative compilation check.
2. **Default regression**: compare v1.4.6, v1.4.7 and this v1.5.0 with all experiments off, same 5-minute video section, same source/target, same settings, controlled memory contents. Track median, mean, P90, P95, typical model calls, misses, confirmed-but-unpresented packets, visible PiP continuity, thermal changes and power.
3. **Low latency**: test with strategy off/on, first-run and warmed, fresh-memory bypass and steady replay, different language pairs, on an iOS 26.4+ phone with traditional language packs installed. Confirm quality/power tradeoff and no wrong cross-model memory reuse. On older iOS, verify the setting is unavailable and default translation continues.
4. **Change sampler**: very small caption changes, low contrast, fast motion, static screens, moving backgrounds, different OCR areas and 90°/180°/270° rotation. Confirm the periodic OCR probe still scans changed text.
5. **Movie lyrics**: overlapping lyrics, 2–5 visible lines, scrolling text, UI elements above and below, two speakers, nonaligned blocks, and unusually large labels. Compare omissions and unwanted extra text.
6. **Incremental batch**: out-of-order responses, cancellation/supersession mid-batch, invalid/duplicate response IDs, changed language/rules/protected context, memory clear, fresh-test, private session, repeated sentences and full batch failure. Check that no speculative result reaches history/persistent storage without confirmation.
7. **PiP direct**: pixel-by-pixel text screenshots against existing renderer at each theme, font, orientation, scale, speaker highlighting, line wrapping and window size. Check heartbeat queue pressure and recovery from render failure.
8. **Profiling**: record OCR, TranslationBatch, and PiPFrame intervals in Instruments under cold/warm, static/moving, and constrained-memory conditions. Do not promise a numerical gain absent real-device evidence.

Current outcome: implementation committed to the 1.5.0 development branch; compile and device acceptance are pending. These optimizations may regress performance or quality, hence the reversible toggles.
