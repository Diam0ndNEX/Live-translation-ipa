# ScreenLingo 1.5.0 — Settings architecture and ownership

This changes the navigation and placement of controls, not their stored keys, default values, translation models, history format, or memory database.

A single keyword-search field matches task names and aliases, including previous “Smart pipeline” phrasing. The prior SmartPipelineSettings entry remains a wrapper forwarding to Experimental Features if an older route is invoked.

## Invariants

1. All `@AppStorage` keys retain existing values. Merely moving the UI never calls `resetKeys`, writes a new default, migrates or deletes history.
2. The experimental model, batch reuse, frame sampling, lyric grouping and direct PiP flags remain **false by default**.
3. Each editable control has exactly one owning settings page. Experimental Features only **reads** `skipUnchanged` and `mode` to disable options whose prerequisites are absent.
4. Page-specific reset buttons affect only that page's controls. The existing global backup and restore still use `TranslatorEngine.settingKeys`.
5. Save-history changes and erase confirmation remain in History & storage. PiP output style is independent of feedback/copy/speech. Diagnostics test mode remains distinct from normal translation memory settings.
6. The interface remains usable on supported iOS 18+, with iOS 26.4-specific translation controls guarded by availability.
7. `scripts/test_experimental_settings.py` is run by the IPA workflow to check unique ownership, navigation, preserved defaults and required callbacks. Release compilation, IPA packaging and physical-device layout/accessibility are separate acceptance steps.

## Manual acceptance

- Visit each page from Settings; search “subtitle”, “history”, “translation”, “smart pipeline”, “low latency”, and “photo” to verify appropriate results.
- Test VoiceOver labels, Dynamic Type and long localized descriptions.
- Compare saved settings before/after opening the redesigned pages and restarting the app; verify presets, saved translation memory, history and privacy flags unchanged.
- Change settings while capture runs; verify correct processing invalidation and no stale or omitted PiP subtitle.
- Test per-page reset, settings export/import, and erase-history confirmation separately.
- Confirm new experiments still off by default and mature options still preserve previous on/off state.

This settings redesign should not be mistaken for proof of a translation performance speedup. Refer to `docs/v1.5.0-acceptance.md` for the full pipeline acceptance criteria.
