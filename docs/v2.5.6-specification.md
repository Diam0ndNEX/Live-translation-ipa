# ScreenLingo 2.5.6 (build 124): growing subtitles settle before translation, as built

Base: `claude/screenlingo-v2.5.5`. Work branch: `claude/screenlingo-v2.5.6`. Draft PR into the base branch.
**Nothing was compiled or run in chat** (no Swift compiler). All `scripts/test_*.py` were run; the tracker was checked with a Python port. The GitHub Actions run is the first real test.
**Every effect is UNVERIFIED.** The report has no subtitle text, so growth is inferred from timing and code.

## 1. Evidence and reasoning
- Owner report on 2.5.4: the same sentence is translated and shown several times with different structure; "nothing is fixed" about punctuation, labels or layout, so the fix must not rely on them.
- Report b122 (metadata only, one 4.7-minute run): 121 of 256 gaps between shown captions under 450 ms, in runs of up to 7; median gap between first OCR sightings of consecutive captions 466 ms. This fits subtitles that are typed or faded in, where each step is confirmed, translated and shown. It is a fit, not proof.
- Code: every confirmed reading goes to `handleContent`; a different text supersedes the active caption, cancels its translation and starts a new one. Each step therefore costs a model call (about 340 ms) and a replacement on screen, and the queue builds up during a burst.

## 2. Design (flexible by construction)
`CaptionGrowthTracker` (`Shared/TranslationSystem+V256.swift`, pure) uses the text alone: a reading is **growth** when the previous confirmed reading (normalized, at least 4 characters, not older than 2.5 s) is the start of it (85% common prefix, tolerating a misread letter) and it is longer. No punctuation, speaker name, language or screen position is used.
- **Hold (confirmed reading that is growth):** `holdGrowingCaption` keeps it, latest wins, and replays it once (`replayed: true`) when the text has been unchanged for the quiet period. The quiet period is learned from the video: 1.3 times a moving average of the time between growth steps, between 0.18 and 0.6 s, starting at 0.35 s. The total hold never exceeds 0.9 s (so growing text cannot starve), and the replay must happen within the existing 1.2 s expiry.
- **A different caption** drops a held state (the screen has moved on) and is handled at once. `clear` and context changes reset the tracker.
- **Early translation:** a first reading that only adds text to the last confirmed one is not translated ahead (`isGrowingFirstReading`), because the last state is translated after the wait. Fewer wasted model calls and a shorter queue are the efficiency side of this change.
- **Nothing waits when text is not growing**: the first state of any caption is handled as before.
Switch "Growing subtitles settle before translation" (`growthSettle`, report arm `growthSettleAB`), Legacy only, default ON, pinned per session; OFF gives 2.5.5.
Counters and report table "Growing subtitles (2.5.6)": growth steps seen, held, steps replaced by a newer one (never translated), released, dropped, early translations skipped.

## 3. Costs and risks (not measured)
- A growing subtitle appears about one quiet period (0.18 to 0.6 s) later than before; its OCR-to-PiP time includes the wait. Fewer model calls and no queue behind obsolete steps may offset this; only a same-clip A/B shows the net.
- The first state of a growing subtitle is still translated and shown (growth is only known once the second state arrives). The change removes the steps between the first and last, not the first.
- A subtitle that lives shorter than the wait and is followed by a different one is dropped while held (counter "dropped"). A text that changes at the start (accent flicker, a different first word) is not recognised as growth, so those steps are handled as before.
- A partial OCR reading of a static subtitle followed by the full reading is also treated as growth; that is intended.

## 4. Not changed
Pixel confirmation and the confirmation rule (2.5.4 L1) were not touched; the text-block join is 2.5.5. The choice between several text areas on one screen (`movieTextFocus`) was not read in detail.
