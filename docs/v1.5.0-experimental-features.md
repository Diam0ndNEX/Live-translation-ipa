# ScreenLingo v1.5.0 — Experimental Features (after Settings redesign)

The Settings redesign moves *established*, normally enabled Smart Pipeline controls to the pages they affect. It does **not** remove or reset them. The old `SmartPipelineSettings` route remains a compatibility wrapper that opens Experimental Features.

## Opt-in experiments

| Feature | Existing storage key | Initial default | What it should do |
| --- | --- | --- | --- |
| Low-latency translation models | `lowLatencyTranslation` | Off | Select faster/lower-power traditional on-device translation on iOS 26.4+; potentially lower fluency |
| Incremental translation recovery | `incrementalBatchRecovery` | Off | Retain individually completed speculative model outputs for exact-context RAM reuse, never partial captions |
| Subtitle-area change detection | `subtitleAwareChangeDetection` | Off | Sample more pixels in selected upright subtitle region; requires Skip unchanged frames |
| Multiple nearby lyric groups | `preserveRelatedMovieGroups` | Off | Preserve additional nearby aligned lyric rows; only selectable in Movie mode |
| Direct PiP pixel-buffer drawing | `directPiPBuffer` | Off | Avoid intermediate UIImage work; verify output parity |
| Confidence-aware confirmation | `adaptiveConfirmation` + `confirmationDeadline` | Off, 0.6s | Optionally accelerate exceptional OCR confirmation and extend uncertain reads |
| Continuous rotation recalibration | `continuousRotation` | Off | Recheck automatic rotation after initial settlement |

The page also *describes*, but does not add meaningless switches for, automatic numeric profiling and PiP heartbeat backpressure.

## Stable controls moved to task-specific Settings

- **Reading & OCR:** adaptive OCR detail, subtitle tracking, duplicate OCR removal.
- **Languages & text rules:** recent-language context, recovery after repeated language/model failures.
- **Translation & memory:** selective/adaptive speculation, speculative confidence, predictive warm-up, translate-ahead, warm sessions, remembered translation.
- **Subtitle timing:** steady captions, protected confirmed handoffs.
- **Performance & battery:** Smart Cool controller, device power and thermal adaptations.
- **Diagnostics & tests:** fresh translation test that bypasses memory.

All use the same `@AppStorage` keys and old defaults. This is a UI move only; the five brand-new experiments stay off by default, while existing stable features maintain their saved on/off values.

## Verification

`scripts/test_experimental_settings.py` checks task-based routes, one editable owner per setting (except two read-only prerequisite values), callbacks, and default values. It runs in the Release IPA CI workflow. Also inspect `docs/v1.5.0-settings-redesign.md` for device and accessibility acceptance, and `docs/v1.5.0-optimization-research.md` for performance-specific tests. New optimization strategies have not yet been proven faster on device.
